## Структура файлів вхідних даних
У каталозі `labs/lab02/data/data_v15/` знаходяться такі файли:
* `sudo.log` — журнал виконання привілейованих команд у форматі `[Timestamp] user=... tty=... pwd=... target=... command=...`
* `alert_commands.txt` — список сигнатур загроз та небезпечних команд (`chmod 777`, `nc`, `nmap`, `/etc/shadow`).
* `_manifest.json` — службовий маніфест тестових даних.
